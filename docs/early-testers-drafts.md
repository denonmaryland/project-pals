## Herdr community

I've been building Project Pals, a terminal-first Herdr layout that gives your coding agents
pocket pets, named topics, a shared task board and a Desk for messages.

I'm looking for a few early Linux testers to try the first ten minutes: install, hire one pal
in a disposable folder, and send it a small task. Tell me where you got stuck, what felt
confusing, or which harness worked. A successful first run is useful feedback too.

It's early software, Linux only, and needs a systemd user session, Herdr 0.1.8+ and herdr-core
0.1.11+, both below 0.2. Bring an installed, signed-in coding harness; its normal usage costs
apply. Claude Code is tested daily and Codex has been tried as a pal; more reports from
Antigravity CLI and other harnesses would help. Hooks and the approval gate cover Claude Code
and Antigravity CLI only, and the gate catches mistakes rather than providing isolation.

Start here (setup changes and uninstall included):
https://github.com/denonmaryland/project-pals#try-it-in-10-minutes

Report here: https://github.com/denonmaryland/project-pals/issues/new/choose
`pal report` prints a local diagnostic with raw log text omitted; review it before pasting.
If your release doesn't have it yet, just include the versions manually. Please keep private
projects, prompts and account details out of public reports.
